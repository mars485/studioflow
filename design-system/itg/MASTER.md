# ITG — Dark Graphite

## Назначение
Рабочая CRM/ERP веб-студии. Дизайн помогает видеть договорённости, сроки и следующий шаг, а не имитирует рекламный лендинг. Существующие маршруты, API, разрешения, формы и данные не меняются.

## Палитра и роли
| Токен | Значение | Роль |
| --- | --- | --- |
| canvas | `#181C1B` | Основной фон |
| surface | `#202624` | Панели и карточки |
| elevated | `#28312D` | Диалоги, hover |
| text | `#EEF3EF` | Основной текст |
| muted | `#A8B5AC` | Вторичный текст, подписи |

Дополнительно: sidebar `#141816`, border `#39473F`, control border `#65776B`, accent-soft `#243C2D`, on-accent `#14251A`, danger `#FFACA6`, danger-surface `#3B2525`, warning `#EDC58C`. Обычный текст ≥4.5:1. Ошибки и просрочки имеют текстовое обозначение, а не только цвет. Цвета стадий, заданные пользователем, сохраняются.

## Типографика и геометрия
- Локальный Golos Text, кириллица/латиница; fallback Segoe UI, sans-serif. Один шрифт без внешних запросов.
- Основной текст 14px/1.55; подписи 12px/1.5; заголовки модулей 30px/1.2, вес 600; числовые показатели 34px с tabular-nums.
- Шкала отступов: 4, 8, 12, 16, 24, 32, 40px. Ширина навигации 232px, основной контент до 1600px.
- Радиусы: controls 8px, cards 12px, large panels 16px. Тень только для перекрывающих диалогов.
- Все тексты выровнены влево, суммы таблиц и воронки — вправо. Заголовки без капса и декоративных надписей.

## Композиция
```
Навигация │ Поиск                                  Студия / профиль
          │ Заголовок раздела                     Главное действие
          │ Фильтры / переключение представления
          │ Рабочая область: доска / таблица / сводка
```
Главная: текстовый рабочий блок + фактическая сводка задач, проектов и follow-up; ниже показатели продаж, широкая воронка и узкая панель внимания. Не использовать выдуманные тренды, активность или выручку.

На планшете навигация сжимается в rail с доступными именами. На телефоне 375px: rail 54px, одноколоночный контент, фильтры переносятся, доска/таблицы/календарь прокручиваются внутри. Выход остаётся доступен. Диалоги вписываются в viewport, формы сохраняют введённое при ошибке.

## Компоненты и состояния
- Primary: зелёная заливка, тёмный текст; secondary: графит, видимая граница; selected: приглушённый зелёный с текстом и aria-состоянием.
- Поля: тёмная поверхность, контрастная граница; focus: outline 2px accent с offset 3px; checkbox нативный.
- Карточки сделок: название → компания/контакт → сумма → следующий контакт; hover меняет границу, не положение карточки.
- Таблицы: спокойная шапка, разделители строк, подсветка hover. Финансовая печать остаётся чёрной на белом.
- Loading/empty/error/retry/disabled сохраняются, ошибка — контрастная красная панель.
- Иконки: существующий Lucide, единая толщина. Декоративные иконки скрыты от screen reader.

## Motion
120ms для кнопок и полей, 180ms для раскрытия диалога, easing cubic-bezier(.2,.8,.2,1). Только color/background/border/opacity/transform; без transition:all. Никаких бесконечных декоративных анимаций. prefers-reduced-motion отключает переходы и анимации.

## Правила CSS
- Единственная точка входа — `frontend/src/app.css`: `@layer legacy, theme`.
- Исходные модульные layouts импортируются в `legacy`, семантическая тема — в `theme`. Импортировать CSS непосредственно из компонентов нельзя: unlayered-правила обойдут порядок слоёв.
- Базовые роли оформляются низкоспецифичными `.itgTheme :where(...)`, после них — компоненты и состояния. Не повышать приоритет через `#root` и `!important`.
- Primary-действия имеют явный класс `primary`; их нельзя определять по `:first-child` или наличию/отсутствию `class`.
- Составные поля поиска и выбора воронки имеют одну рамку и один focus ring на контейнере; внутренний input/select — без второй рамки.
- Текстовые ссылки, кнопки удаления тега, иконки закрытия и текстовое «Закрыть» имеют отдельную геометрию. Не навязывать им размер обычной кнопки.
- Отступы контента и верхней панели используют один `--itg-gutter`. Проверять широкий viewport 1920px и короткий 667×375, а не только desktop и portrait phone.
- Выпадающие меню select в поддерживающих Chromium-браузерах используют `appearance: base-select` и графитовый `::picker(select)` с зелёным выбранным пунктом. Нативная семантика, значения и клавиатура сохраняются; при отсутствии поддержки остаётся штатный select.
- `::picker-icon` выравнивается по правому краю через автоматический margin, а не фиксированный отступ после текста; проверять широкие select в настройках и ролях участников.
- Подпись чекбокса панели уведомлений — `inline-flex` с центрированием и gap 8px. Кнопка обновления интеграций находится в отдельной панели действий с отступом 20px до следующей карточки.
- Пояснение CSV — доступная через `aria-describedby` всплывающая подсказка при hover/focus с закрытием по Escape. Она не участвует в размерах панели и не смещает соседние кнопки; ошибка экспорта остаётся видимой в потоке.

## Проверка решения против брифа
Зелёный на графите задан пользователем, но не превращается в неоновый шаблон: без glow, градиентов, наклонных рамок и гигантских стрелок. Отличительный элемент — типографическая рабочая сводка, построенная на реальных данных студии. Существующая архитектура React/CSS сохраняется: отдельный слой семантических токенов и темы поверх существующих модульных layouts.

- Backend и production не затрагиваются.
