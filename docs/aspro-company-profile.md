# Карточка компании

23.10.2026 в тестовом портале `https://7e96.aspro.cloud/` изучена доступная карточка компании через ссылку из сделки. REA evidence: `ev_6669d37eea8568c3eec6c4ba07c12af266b7a42cae77828b18fe40d5fc5f5034`. В UI наблюдались общие сведения, сайт, рабочие телефон и email, описание, контакты, а также вкладки сделок, задач, проектов, документов, платежей и событий. Личные значения из карточки в репозиторий не переносились.

В StudioFlow карточка компании открывается из сделки и из списка «Компании». Можно искать по имени, телефону и email, создать компанию, сохранить название, телефон, email, сайт и описание, увидеть связанные сделки и перейти к сделке. При точном совпадении имени новая форма предупреждает о возможном дубле; автоматическое объединение не выполняется. Владелец и администратор могут удалить компанию без сделок. Любой участник своей студии может просматривать и редактировать компании; чужой workspace возвращает 404. Введённые значения остаются в форме при ошибке сохранения.

Модель `clients` уже содержит нужные поля, поэтому миграция не требуется. Отдельные контактные лица и связи «контакт ↔ компания», реквизиты, адреса, файлы, теги и другие вкладки Aspro остаются следующими сценариями; строка матрицы остаётся `IN_PROGRESS`.
