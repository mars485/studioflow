# Шаблоны плана проекта

P2, TESTED в описанном объёме. Официальная справка подтверждает сценарии [создания шаблона из проекта](https://aspro.cloud/help/articles/3084-3145-23490--sozdanie-shablona-na-osnove-proekta) и [создания/редактирования шаблонов](https://aspro.cloud/help/articles/3084-3145-6851--sozdanie-i-redaktirovanie-shablonov-proektov). При исследовании 24.10.2026 страницы были закрыты проверкой подключения, доступны заголовки и поисковые выдержки; подробные правила референса не подтверждены. Ниже — ограниченный самостоятельный сценарий StudioFlow.

- OWNER/ADMIN сохраняет текущий порядок работ проекта как независимый шаблон: имя, описание и упорядоченные этапы.
- Копируются названия и относительные календарные смещения дат от самой ранней даты плана. Не копируются люди, состояния выполнения, деньги, клиенты, файлы, задачи, контакты, события и доступы.
- При создании проекта вручную или из выигранной сделки можно выбрать шаблон и дату начала. Этапы получают новые ID, PLANNED и пустого ответственного; смещения переносятся на указанную дату. При отсутствии явного конца проекта он вычисляется по плану. Заданный конец не может быть раньше конца плана.
- Шаблон доступен только в своём workspace; создавать проекты из него могут все участники, изменять/удалять шаблон — только OWNER/ADMIN. Изменение/удаление шаблона не меняет созданные проекты.
- Максимум 200 шаблонов в студии, 500 этапов в шаблоне и 10 лет смещения. Пустой план шаблоном не сохраняется. Имена уникальны в workspace с учётом регистра.
- Снимок создаётся транзакционно под блокировкой проекта, применение — в транзакции создания проекта. Ошибки не оставляют пустой/частично созданный проект.

Приёмка: сохранить план → создать из шаблона с другой датой → проверить порядок/смещения/сброшенные назначения → изменить/удалить шаблон → проект не меняется; чужой workspace и MANAGER на управление получают отказ; исходные данные сохраняются.

Реализация `0020_project_templates`, `project_templates.py`, сервис применения; UI во вкладке «Порядок работ», форме создания и списке шаблонов раздела «Проекты». Проверено 24.10.2026: backend 72/72 (3 новых сценария, включая отдельные per-request сессии для проверки rollback), frontend 53/53 + build, E2E 6/6. Браузерный проектный сценарий сохраняет план и создаёт копию с другим началом, проверяя перенесённый Гант. Миграция `0020` применена к dev после резервной копии. Downgrade удаляет шаблоны, но не изменяет уже созданные проекты и их планы.
