# CRM: визуальный стиль IT GROUP

24.10.2026. Продолжение согласованной главной: графитовая навигация, красный `#E31E24`, белые карточки и Arial/Helvetica. Используются принципы рабочего пространства Aspro, без копирования кода, ассетов и точной компоновки.

## Границы среза

- Только оформление CRM: общая с главной верхняя панель, заголовок, разделы компаний/контактов/моего дня, выбор воронки, поиск, follow-up фильтры, панель управления и карточки канбана.
- Сохранены существующие API, доступ по ролям, формы, ошибки, черновики, справочники и карточка сделки. Цвета стадий из API имеют приоритет над фирменными значениями по умолчанию.
- Доска прокручивается внутри страницы. При перетаскивании подсвечивается целевая стадия; сохранение выполняется прежним API.
- `WorkspaceTopbar.tsx` переиспользуется главной и CRM; остальные разделы не переоформлены. Backend, миграции и реальные данные в этом срезе не меняются.
- `crm-design.spec.ts` использует только перехваченные API-запросы и запрещает записи; скриншоты явно помечены демонстрационными. Проверяет поиск, фильтры, открытие точной сделки с клавиатуры, переход в уведомления и внутреннюю прокрутку на 390px.

Проверено: frontend 80/80 тестов и production build; полный изолированный браузерный прогон 13/13, включая реальное сохранение drag-and-drop CRM и регрессию главной. Backend integration suite отдельно не запускался: серверный код не менялся. В новом visual fixture исправлен ответ custom-fields на контракт `{values: []}`.
