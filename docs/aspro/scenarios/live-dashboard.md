# Реальные сводка и аналитика продаж

P3, TESTED в описанном объёме. В исследованном рабочем столе Аспро наблюдались доски обзора задач и отчётов по продажам (см. `feature-inventory.md`). Метрики ниже — собственная явно определённая сводка StudioFlow, не воспроизведение закрытых формул референса.

- «Главная» и «Аналитика» читают данные PostgreSQL доступной студии; демонстрационные компании, задачи и суммы больше не показываются.
- Продажи: фильтр по воронке и необязательной дате создания сделки от/до включительно в timezone студии. Без дат — все сделки, включая выключенные воронки. Стадии и ответственные показывают количество и суммы раздельно по валютам.
- Конверсия — текущие WON / (WON + LOST) выбранной когорты. Это не историческая конверсия переходов: смена стадии меняет показатель, удалённые сделки в него не входят. Открытые сделки не входят в знаменатель.
- Сводка работы всегда по всей студии, независимо от фильтра продаж: незавершённые задачи, просроченные задачи (срок раньше текущего серверного времени), активные/архивные проекты, просроченные follow-up открытых сделок, открытые сделки без follow-up.
- Финансовые документы и банковские поступления в эту сводку не входят; сумма WON — не выручка и не факт оплаты. Роли совпадают с доступом к CRM, чужой workspace не раскрывается.
- SQL-агрегация без загрузки всех сделок в браузер. Пустая студия показывает нули, при ошибке есть повтор и явно нет вымышленных KPI.

Приёмка: создать/перенести сделки → изменить KPI после обновления/reload; разные workspace изолированы; фильтр дат включает локальные границы дня; суммы не смешивают валюты; подразделение работы не выдаётся за когортный отчёт.

Проверено 24.10.2026: backend 92/92, frontend 66/66 + build, E2E 8/8. `test_analytics.py` — пустые данные, переходы стадий, роли/workspace, локальные границы суток, раздельные валюты и сводка задач. `LiveDashboard.test.tsx` — KPI сервера, фильтр, обновление и отсутствие вымышленных значений при ошибке; `e2e/integrations.spec.ts` — созданная через API заявка учитывается на «Аналитике» и «Главной». Новых таблиц/миграций нет. Демонстрационные записи в App.tsx заменены, данные БД не переписывались.
