# Календарь задач

P2, TESTED в описанном объёме. Представление «Календарь» наблюдалось в общем модуле задач: [сценарий](tasks-module.md). Конкретная сетка и правила ниже — собственное решение StudioFlow.

- Месяц, недели с понедельника, переходы назад/вперёд и «Сегодня».
- Те же сохранённые задачи, что в Канбан/списке; загружаются все страницы API, не только первые 200 задач.
- Даты показываются в локальном часовом поясе браузера, как существующая форма `datetime-local`; пояс указан в UI.
- Задача с началом и сроком видна во всех пересекаемых днях; только со сроком/началом — в соответствующем дне. Подзадачи также видны. Без дат — отдельный блок.
- Фильтр исполнителя и скрытие завершённых; переход из календаря в обычную карточку для редактирования.
- Создание на выбранный день с предзаполненным сроком 18:00 локального времени. Сохранение через прежний API с UTC и проверкой порядка дат. При ошибке форма сохраняется.
- Без новых сущностей и миграций. Не входит: синхронизация Google/CalDAV, повторения, drag-and-drop сроков и Гант.

Приёмка: переход декабря/января, локальная полночь и многодневная задача; задача после создания/правки/reload находится в правильном дне; недатированные не теряются; >500 задач доступны через пагинацию.

Реализация: `TaskCalendar.tsx`, общий `loadTasks` с пагинацией, форма задачи с выбранным днём. Проверено 24.10.2026: `TaskCalendar.test.tsx` (5 тестов на сетку, годы, локальные даты, диапазон, фильтры, 501 задачу); `e2e/calendar.spec.ts` — создание на день → правка на 00:30 в Asia/Yekaterinburg → reload → правильный день. Общий срез: frontend 45/45 и build, E2E 5/5.
