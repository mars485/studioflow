# Отдельный раздел клиентов

P1, TESTED в описанном объёме. Ранее каталоги компаний/контактов работали только из CRM, а пункт «Клиенты» ошибочно показывал демонстрационный Dashboard. Отдельный экран использует уже проверенные workspace-scoped CRUD API и редакторы, без новой сущности и миграции.

- Студия, вкладки «Компании / Контакты», поиск по имени/названию, телефону и email.
- Создание/редактирование через существующие карточки, связи контактов с компаниями и переход к сделке в нужной студии.
- Ошибка загрузки с повтором, пустые состояния; при ошибке сохранения форма не закрывается. Переключение студии недоступно при открытой карточке.
- Удаление доступно OWNER/ADMIN, действующие серверные ограничения связей сохранены. Дедупликация и слияние записей в этот сценарий не входят.

Проверка 24.10.2026: `Clients.test.tsx` — карточка компании, переход к сделке, блокировка смены студии и сохранение ошибочного черновика; `e2e/crm.spec.ts` — отдельный пункт «Клиенты», чтение сохранённого телефона и переход обратно в сделку. Общий срез до учёта времени: 58 frontend-тестов, build и 7 E2E прошли.
