## A03. Definition of Ready и Definition of Done

**DoR:** [ ] понятна цель; [ ] определены границы; [ ] критерии наблюдаемы; [ ] известен сервис и владелец; [ ] присвоен риск; [ ] доступны нужные материалы; [ ] определены проверки; [ ] для L3–L4 оценены зависимости, данные и восстановление. Невыполненный пункт помечают причиной и решением.

**DoD:** [ ] реализован согласованный объём; [ ] пройдены применимые тесты; [ ] код или артефакт идентифицируем; [ ] выполнено ревью по риску; [ ] обновлена документация; [ ] проверено фактическое поведение; [ ] записаны результаты и ограничения; [ ] для production подтверждены релиз и мониторинг. Задача с непроверенным результатом получает статус ожидания проверки, а не «готово».
