## A16. Реестр исключений из регламента

Поля записи: ID; дата; проект/сервис; нарушаемый пункт; основание; точный объём; уровень риска; владелец; согласующий; начало и срок окончания; компенсирующие меры; способ контроля; дата пересмотра; статус «действует/истекло/закрыто»; ссылка на решение. Исключение действует только в согласованных границах. По окончании срока его закрывают, продлевают новым решением или меняют стандарт через раздел 14.8.
