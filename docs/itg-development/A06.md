## A06. Git и Pull Request checklist

**До PR:** [ ] задача связана с веткой; [ ] область изменений соответствует ТЗ; [ ] чужие изменения сохранены; [ ] нет секретов и отладочных артефактов; [ ] коммиты понятны; [ ] миграции и конфигурация учтены.

**В PR:** краткая цель; ID задачи; изменение поведения; тесты с результатами; влияние на API/БД/данные; риск и rollback; документация; снимки интерфейса при необходимости; известные ограничения. **Перед слиянием:** [ ] обязательные проверки успешны; [ ] замечания обработаны; [ ] требуемое ревью и разрешения получены; [ ] версия релиза определима. Слияние следует правилам проекта и не означает автоматический production-релиз.
