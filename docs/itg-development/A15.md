## A15. KPI и аудит качества

**Период:** месяц; проекты; источник данных; ответственный; дата. Показатели: успешность обязательных CI-проверок; дефекты после релиза; доля релизов с отказом; время восстановления; доля изменений с обязательными проверками; доля требуемых обновлений документации; просроченные P1/P2. Для каждого фиксируют числитель, знаменатель, исключения, тренд, пояснение и действие. Целевые значения назначают после базовой линии. Выборочный аудит проверяет связь задачи, кода, теста, разрешения, релиза и фактического результата; выводы не используют для сокрытия ошибок.
