## A10. README и документация API

**README:** назначение; владелец; архитектура в одном абзаце; требования; локальный запуск; безопасная конфигурация через `.env.example`; тесты; сборка и релиз; зависимые сервисы; наблюдаемость; резервное копирование; ссылка на runbook; история изменений. Для CMS дополнительно указать версию ядра, тему/шаблон, плагины или модули, способ обновления и редакторские роли. Для NestJS — структуру модулей, команды сборки и миграций, схему конфигурации и генерацию API-документации.

**API:** базовый адрес по средам; аутентификация и права; версия и совместимость; операции с методами, путями, параметрами, схемами запроса/ответа и кодами ошибок; пагинация и лимиты; идемпотентность; примеры без реальных данных; журнал изменений и порядок вывода старых версий. Документация меняется вместе с контрактом.
