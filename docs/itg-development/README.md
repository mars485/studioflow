# Пилот IT GROUP Development в StudioFlow

Статус: проект пилота. Комплект шаблонов A01–A16 создан из консолидированной редакции IT GROUP Development v1.0 от 28 октября 2026 года. Основной регламент ещё требует сверки исходного текста разделов 1–3; этот каталог не вводит новые обязательные правила для текущих задач автоматически. Первое пробное применение описано в [записи пилота](PILOT-RECORD.md).

## Применение на одной следующей задаче

1. Выбрать одну новую задачу с ограниченным объёмом, не затрагивающую production и реальные данные. Зафиксировать её ID, владельца и риск.
2. Заполнить A01 (Mini или Standard), A02 и применимые пункты A03 до начала реализации.
3. При разработке использовать A04 для агента, A06 для PR и A07 для проверки. Существующие правила `AGENTS.md`, `README.md` и `docs/REFERENCES.md` сохраняют приоритет.
4. После фактической проверки заполнить DoD из A03 и записать ограничения. Если задача дойдёт до production, использовать A08, A09 и A14 только после отдельного разрешения на релиз.
5. На ретроспективе оценить, какие поля помогли, а какие оказались избыточными. Предложения по изменению шаблонов оформить отдельным решением, не переписывая утверждённый регламент молча.

Критерий завершения пилота: одна задача проходит полный документированный цикл от критериев приёмки до доказательства результата, а владелец проекта подтверждает полезность и необходимые поправки. В качестве первой задачи выбрано добавление самого комплекта шаблонов в документацию StudioFlow. Проверка применимости шаблонов на продуктовой задаче остаётся следующим этапом.
