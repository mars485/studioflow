## A14. Change Request

ID и связь с задачей; сервис; инициатор; цель и причина; категория изменения и риск L1–L4; затронутые компоненты, пользователи, данные и доступы; точный объём; план реализации по шагам; проверки и критерии Go/No-Go; окно; backup и проверка; rollback; согласующий и время разрешения; журнал выполнения; результат и отклонения; post-change проверка; решение о закрытии. Для L1–L2 допускается карточка задачи с теми же применимыми сведениями. Для аварийного изменения добавляют ID инцидента и причину ускорения.
