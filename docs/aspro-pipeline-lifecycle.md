# Несколько воронок продаж

23.10.2026 на доступном тестовом портале `https://7e96.aspro.cloud/` открыт выбор воронки и форма «Новая воронка продаж». В форме наблюдались имя, тип «Общедоступная», описание, вкладка пользователей и список этапов с цветами. REA подтвердил страницу создания воронки: evidence `ev_699c303293b333a90ee8fb190c2420ec4577870624be9f0f5c7f069bed40543c`. [Официальная справка по созданию и редактированию](https://aspro.cloud/help/articles/3301-7329-7330--sozdanie-i-redaktirovanie-voronki-prodazh/); [по удалению и деактивации](https://aspro.cloud/help/articles/3301-7329-7331--udalenie-i-deaktivaciya-voronki-prodazh/).

В StudioFlow владелец и администратор студии могут создать вторую воронку с четырьмя начальными этапами, переименовать её, выбрать основной, отключить и снова включить. Удаление разрешено лишь для воронки без сделок. Последнюю активную воронку нельзя отключить или удалить. При отключении основной другая активная становится основной. Менеджер может выбирать активные воронки и работать со сделками, но не менять настройки.

Данные остаются в существующих таблицах `pipelines` и `pipeline_stages`; новая миграция не требуется. API и UI изолированы по workspace. Существующие сделки в отключённой воронке сохраняются и возвращаются в доступный интерфейс после её включения. Форма сохраняет введённое имя при ошибке. Ограничение этой итерации: тип доступа, описание и управление пользователями воронки ещё не реализованы и не считаются достигнутым соответствием Aspro.
