# Задачи: проверенное поведение доступного портала

Источник: авторизованный UI `https://7e96.aspro.cloud/_module/task/view/board` 23.10.2026. REA evidence для формы «Дополнительно»: `ev_d8b0862920e64c2c67a1e98e72e75d5ddff6a760fe3796be8597f7b624d9f71c`. Исследование выполнено на демоданных; новые задачи в исходной системе не создавались.

## Наблюдаемые страницы и поля

- Представления: «Планирование», «Канбан», «Список», «Гант», «Календарь».
- Kanban в рабочем процессе по умолчанию: «Сделать», «В работе», «Ожидает контроля», «Завершено». В колонках показано количество задач и суммарное время.
- Создание, вкладка «Основные»: обязательное название, приоритет (низкий, средний, высокий), подробное описание, чек-лист, файлы, ответственный, постановщик, соисполнители, наблюдатели, даты начала и крайнего срока, рабочий процесс, контроль после выполнения, подзадачи. Кнопки «Сохранить» и «Сохранить и создать еще».
- Вариант «Выбрать несколько» рядом с ответственным поясняет, что для каждого выбранного ответственного создаётся своя задача.
- Вкладка «Дополнительно»: список, оценка времени, теги, связь с проектом/сделкой/контрагентом, напоминание, регулярное повторение.
- На доске видны связи с проектами и сделкой, теги, чек-листы, даты, трудозатраты и процент готовности.

## Первый сценарий StudioFlow

Первый шаг реализован как задачи внутри карточки сделки: workspace scoped CRUD, название, описание, приоритет, статус, ответственный из участников студии, даты и связь со сделкой. Подробности и проверки: [задачи из сделки](aspro-deal-tasks.md). Общий модуль задач с представлениями и операциями вне сделки ещё не реализован. Затем предстоят подзадачи, чек-листы, комментарии, файлы, повторение и учёт времени.

Критерии первой итерации: создание и редактирование сохраняются после перезагрузки; чужая студия и чужая сделка недоступны; ответственный должен состоять в студии; крайний срок не раньше даты начала; смена статуса отражается в списке; удаление не повреждает сделки и участников. Проверки для нескольких ответственных и повторения остаются отдельными сценариями; напоминания реализованы отдельно ([сценарий](aspro-task-reminders.md)).

## Не проверено

Права на создание/редактирование по ролям Aspro, точные ограничения сроков и вложений, массовые операции, мобильный вид, сортировка, ошибки API, отправка уведомлений и реальные правила регулярных задач. Их нельзя считать подтверждёнными по этому снимку.
