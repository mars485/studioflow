# Контактные лица и связи с компаниями

23.10.2026 в доступном портале `https://7e96.aspro.cloud/` изучена форма создания контактного лица из карточки компании. REA evidence: `ev_326327d4880a21f89e88d5bcdd6a2ee6e00524245cb1801f1a732ebe14b21500`. Наблюдались имя (обязательное), фамилия, отчество, рабочие телефон и email, сайт, описание, связь с одной или несколькими компаниями, реквизиты и адреса. Реальные данные портала не переносились.

StudioFlow теперь хранит контакт отдельно от компании. Контакт может быть связан с несколькими компаниями одной студии. В каталоге доступны поиск, создание, редактирование, удаление неиспользуемого контакта и список его сделок. Из карточки компании можно создать контакт с заранее выбранной связью. В сделке можно выбрать контакт только из связанных с выбранной компанией; прежнее текстовое поле контактного лица сохраняется для исторических сделок. API проверяет workspace для каждой операции и запрещает удалять контакт или разрывать связь с компанией, пока контакт используется в её сделке.

Данные: миграция `0007_contacts.py` создаёт `contacts`, `contact_clients` и добавляет nullable `deals.contact_id` с внешним ключом в пределах workspace. Старые сделки сохраняются без изменения контактного текста. Входные схемы ограничивают длины и отклоняют повторяющиеся/чужие компании. UI сохраняет введённые значения при ошибке. Подтверждение: backend 32/32, frontend 22/22, браузерный E2E 1/1 на изолированной PostgreSQL.

Оставшиеся поля Aspro — обращение, категория, сфера деятельности, дополнительные телефоны и email, адреса, реквизиты, файлы, теги и наблюдатели — отдельные сценарии и не считаются выполненными здесь.
