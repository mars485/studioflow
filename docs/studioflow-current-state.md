# StudioFlow: текущее состояние

Обновлено по локальному коду 24.10.2026. Это аудит реализации, а не подтверждение production.

## Архитектура

- Backend: FastAPI, SQLAlchemy AsyncSession, PostgreSQL, Alembic; код в `backend/app`.
- Frontend: React, TypeScript, Vite; код в `frontend/src`.
- Данные: `User`, `Workspace`, `WorkspaceMember`, `AuthSession`, `AuthThrottle`, `Client`, `Contact`, `ContactClient`, `Pipeline`, `PipelineStage`, `Deal`, `DealActivity`, `DealTag`, `DealTagLink`, `DealWatcher`, `DealContact`, `DealAttachment`, `DealCustomValue`, `Task`, `TaskStatus`, `TaskChecklistItem`, `TaskWatcher`, `TaskReminder`, `Project`, `ProjectStage`, `ProjectMember`, `ProjectContact`, `ProjectEvent`, `FollowUpCompletion` в `backend/app/models/entities.py`.
- Финансовые модели: `Organization`, `FinanceCounter`, `Invoice`, `InvoicePayment`, `Act` в `backend/app/models/finance.py`.
- Дополнительные модели: файлы, уведомления, этапы работ, шаблоны проектов, токены входящих заявок и записи времени.
- Миграции: `0001_initial_schema` … `0025_deal_audit`; все применены к локальному dev после отдельных `pg_dump`. Продакшен не затрагивался.
- Проверки: backend pytest, frontend Vitest и сборка, Playwright E2E в `frontend/e2e/crm.spec.ts`, CI в `.github/workflows/p0-checks.yml`.

## Готово в коде

| Область | Реализация | Ограничение |
| --- | --- | --- |
| Доступ | Регистрация, вход, выход, серверная cookie-сессия, роли OWNER/ADMIN/MANAGER, membership | Нет подтверждения email, восстановления пароля и гибкого RBAC |
| Рабочие пространства | Создание, переименование, участники и роли | Нет команд и произвольных прав |
| Клиенты | Отдельный раздел «Клиенты», каталоги/карточки компаний/контактов, CRUD и связи; CSV OWNER/ADMIN; кандидаты в дубли с причинами/страницами | Нет слияния; совпадение не доказывает дубль |
| Сделки | CRUD, воронки, теги, наблюдатели, канонический основной контакт и дополнительные связи, настоящие файлы PostgreSQL, UTM, пользовательские поля, адресные упоминания | Нет почты/звонков и автодействий; старые метаданные файлов не имеют содержимого |
| Follow-up | Текущее действие, история завершений, «Мой день», фильтры и напоминания задач | Нет email/push-уведомлений |
| Задачи | Канбан, список, календарь, статусы, чек-листы, подзадачи, наблюдатели, оценка времени, связи; ручное время/серверный таймер, ограниченная цепочка повторений после завершения | Нет календарного планировщика повторений и тегов; Гант задач отдельно не реализован |
| Уведомления | Личный workspace-scoped inbox адресных упоминаний, read/read-all и переход в сделку | Нет email/push, уведомления назначений и сработавшие напоминания пока не объединены с inbox |
| Проекты | Создание из выигранной сделки/вручную, команда, контакты, события, задачи, архив; порядок работ, упрощённый Гант и независимые шаблоны с переносом дат | Нет зависимостей/автопланирования; финансы связаны с проектом через счета, не бюджет |
| Входящие заявки | Одноразово показываемый серверный токен leads:create, сроки/отзыв, квота, идемпотентный приём и журнал | Внешние сайт/n8n не настроены |
| Исходящие webhooks | Три события CRM/задач, транзакционная очередь, HMAC, повторы/журнал, отключение и ручной повтор | По умолчанию выключены; нужен согласованный HTTPS endpoint, приватный ключ и отдельный worker; общего конструктора роботов нет |
| Главная/аналитика | Реальные SQL-агрегаты стадий/ответственных/конверсии, локальная когорта дат, валюты отдельно; текущая сводка задач/проектов/follow-up | Не исторический отчёт переходов, не финансовая выручка/прибыль |
| Финансы | Организации, счета из сделки/связь с проектом, статусы, частичные/полные поступления, акты, печать/PDF; OWNER/ADMIN | Нет налогового/бухгалтерского ядра, банков, ЭДО, отправки почты; счёт после создания неизменяемый |
| Защита данных | Workspace scoped API, проверки связей, ограничения БД | Новые сущности должны повторять эти правила |
| Общий поиск | Пять типов объектов, SQL UNION с workspace scope, фильтр/страницы, точные переходы, подзадачи и архивные проекты | Без морфологии, файлов, финансов и поиска между студиями |
