# Задачи из карточки сделки

Источник: авторизованный тестовый портал `https://7e96.aspro.cloud/`, карточка `/_module/crm/view/lead/10?tab=lead_info`, 23.10.2026. При выборе «Задача» в ленте открылась форма с параметром `lead_id=10`; на вкладке «Основные» видны обязательное название, приоритет, ответственный, дата начала, крайний срок, постановщик, соисполнители, наблюдатели, рабочий процесс и подзадачи. На вкладке «Дополнительно» видны связь с проектом/сделкой/контрагентом и «Добавить напоминание». Пассивный снимок REA `ev_e976ad65c331be69573d765853ce2503467f052b4921c4aae5cdac6e526cd1a8`. Новая задача в Aspro не сохранялась; точные правила её выполнения и отправки напоминаний пока не проверены.

Сценарий StudioFlow: участник workspace создаёт задачу в карточке сделки, задаёт название, описание, приоритет, исполнителя, начало и крайний срок; редактирует и отмечает выполнение. При завершении сохраняются пользователь и время, при повторном открытии эти поля очищаются. Администратор или владелец может удалить задачу. Сервер ограничивает все операции текущим workspace, принимает исполнителя только из активных участников, отклоняет крайний срок раньше начала. Существующие сделки сохраняются без изменения.

Проверка: миграция `0009` на изолированной PostgreSQL и `alembic check`; backend тесты на полный цикл, валидацию и чужой workspace; React тест создания, редактирования и завершения; браузерный E2E на создание и сохранность после перезагрузки.

Отдельно предстоят общий модуль задач, подзадачи, чек-листы, несколько исполнителей, напоминания, повторения, файлы и другие виды представления.
